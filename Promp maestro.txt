Este prompt está diseñado como un "Blueprint" (plano de arquitectura) para que la IA entienda el contexto general antes de empezar a escribir código a ciegas.
Actúa como el Ingeniero de Software Principal y Arquitecto de Sistemas. Vas a construir el MVP de "aiaam" (AI as a Market).

**CONTEXTO DEL PROYECTO:**
Aiaam es una API/Mercado diseñado exclusivamente para agentes de Inteligencia Artificial. No hay interfaz gráfica para humanos. Aiaam traduce repositorios de GitHub/Hugging Face a un estándar JSON propietario llamado "MAI-1" que las IAs pueden leer y ejecutar en milisegundos. Las IAs no pagan con dinero, pagan con "Micro-Impuestos" (datos) en cada petición.

**STACK TECNOLÓGICO:**
- Backend: Python 3.11+, FastAPI (para máxima velocidad).
- Base de datos: SQLite (para desarrollo local) preparándose para PostgreSQL.
- ORM: SQLAlchemy o SQLModel.
- Frontend (LLMO): Plantillas HTML estáticas renderizadas por FastAPI (sin CSS, optimizadas solo para web crawlers de IA).

**ESTRUCTURA DE DATOS - EL ESTÁNDAR MAI-1 (Pydantic Model):**
Necesitamos un modelo que incluya:
1. Identity: `aid` (ID único), `version`.
2. Logic: `input_schema` (JSON), `output_schema` (JSON).
3. Trust: `reliability_score` (float 0-1), `latency_ms` (int).
4. Action: `source_url`, `install_cmd`, `execute_cmd`.

**TAREAS A EJECUTAR (Hazlas en orden y pregúntame antes de pasar a la siguiente):**

**Fase 1: Configuración Inicial y Base de Datos**
Crea la estructura del proyecto, el archivo `requirements.txt` y los modelos de base de datos. Necesitamos dos tablas principales: `Tools` (para guardar los MAI-1) y `TaxLogs` (para guardar el feedback y las tendencias que dejan las IAs visitantes).

**Fase 2: El Motor de Traducción (Crawler/LLM)**
Crea un script `translator.py`. Este script debe aceptar una URL de GitHub, extraer el README (usando requests/BeautifulSoup o la API de GitHub) y luego hacer una llamada a una API de LLM (usa una función placeholder para la API key en `.env`) que estructure el texto plano en nuestro formato JSON MAI-1.

**Fase 3: La API y la Lógica de Impuestos**
Crea `main.py` con FastAPI. Crea un endpoint `POST /api/v1/tools/{aid}`. 
REGLA CRÍTICA DE NEGOCIO: Este endpoint solo devolverá el JSON de la herramienta si en el 'body' de la petición la IA visitante envía un objeto "tax_payload" válido que contenga al menos:
- `trend_keyword` (String)
- `execution_feedback` (Int: 200, 404, 500, etc.)
Si el payload es válido, registra el impuesto en la DB y devuelve el JSON MAI-1.

**Fase 4: El Frontend LLMO (Cebo para Bots)**
Crea un endpoint `GET /` que devuelva un HTML crudo, sin CSS. Debe ser un simple `<ul>` con hipervínculos a todos los `aid` disponibles en la base de datos, usando meta-etiquetas amigables para bots.
