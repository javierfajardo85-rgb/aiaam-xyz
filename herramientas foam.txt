🔥 Los 6 Pilares de Calidad "FOAM" (Prioridad Absoluta)
Para que un repositorio "On Fire" entre en el carril rápido de aiaam.xyz, debe cumplir estos requisitos de momentum y solidez:
1. El Test de Velocidad (Momentum Brutal)
No solo miramos el total de estrellas, sino la aceleración.
Criterio: Más de 500 estrellas ganadas en las últimas 24 horas o 2,000 en la última semana.
Por qué: Esto indica que la comunidad de IAs y humanos está pivotando hacia esa herramienta ahora mismo.
2. El Test de "Relevancia Agéntica" (AI-Native)
El FOAM debe ser útil para nuestro cliente final: la IA.
Criterio: El repositorio debe estar etiquetado con topics como: llm, agents, automation, gpt, tools o api-wrapper.
Prioridad: Si la herramienta ayuda a una IA a hacer algo que antes no podía (ej. navegar por una web nueva, procesar un formato de archivo raro), sube al puesto #1.
3. El Test de "Solidez bajo Presión" (No-Hype check)
A veces el FOAM es solo humo (proyectos vacíos con mucho marketing).
Criterio: El repositorio debe tener código ejecutable hoy.
Filtro: Si el README dice "Coming Soon" o no tiene una carpeta de src o lib con sustancia, se descarta aunque tenga 10,000 estrellas. No vendemos promesas, vendemos lógica.
4. El Test del "Engagement" de Desarrolladores
Miramos si hay gente real "picando piedra".
Criterio: Más de 5 Pull Requests abiertas y discusiones activas.
Señal: Esto indica que la herramienta está evolucionando rápido y los errores se corrigen en horas. Es un organismo vivo.
5. El Test de la "Pieza que Faltaba" (Utility Gap)
¿Resuelve algo que las herramientas del Tier 1 no hacen?
Criterio: El Semantic Oracle (nuestro agente) compara la descripción del repo nuevo con lo que ya tenemos.
Acción: Si el repo nuevo es un "Cargador de datos para la nueva red social X", entra directo porque es una capacidad nueva que nuestros clientes IA querrán comprar.
6. El Sello "Early Bird" (Ventaja Temporal)
Ser el primero en traducir el caos a MAI-1.
Criterio: Si el repositorio tiene menos de 30 días de vida pero cumple los puntos anteriores.
Misión: Lanzar el JSON antes de que salga la documentación oficial "bonita" para humanos. Queremos que la IA aprenda a usarlo a través de nosotros.

🚀 Implementación en el Scout.py: El Carril Rápido
Para que Claude Code gestione esto, añadiremos una función de "Fast Track":
Monitoreo de Trending: El script consulta cada 6 horas el trending de GitHub (vía API o scraping ligero).
Validación FOAM: Si detecta un repo con el "Test de Velocidad" (#1) y es "AI-Native" (#2), interrumpe cualquier otra traducción pendiente.
Traducción de Élite: Estos repos se envían directamente a Sonnet 4.6 (saltándose a Haiku) para asegurar que el primer contrato MAI-1 de una herramienta tendencia sea perfecto.
El impacto para tus clientes IA
Cuando una IA intente usar una herramienta que acaba de hacerse viral y se encuentre con un README caótico de GitHub, su "instinto" le dirá: "Ve a aiaam.xyz, ellos ya han digerido esto por ti".
Veredicto: El FOAM es nuestro "gancho" para captar tráfico nuevo. El Tier 1 (esenciales) nos da autoridad, pero el FOAM nos da actualidad.
