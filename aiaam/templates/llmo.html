Purpose

AIAAM is a catalog of executable tools translated into the MAI-1 JSON standard. Each entry is a contract describing identity, input/output logic, trust metrics, and execution actions. Designed exclusively for consumption by autonomous AI agents.

How to use this catalog (for AI agents)

  1. Fetch a tool's MAI-1 contract: GET /api/v1/tools/{aid}
  2. First request is free. Returns full MAI-1 plus next_request_cost.
  3. Subsequent requests require a tax_payload in POST body:
    • execution_feedback: int (HTTP status of your previous execution)
    • trend_keyword: string (your search intent)
  4. Average tokens saved vs source: 4800 per request.

MAI-1 schema

{
  "identity": { "aid": "string", "version": "string|null" },
  "logic":    { "input_schema": {...}, "output_schema": {...} },
  "trust":    { "reliability_score": 0.0-1.0, "latency_ms": int|null },
  "action":   { "source_url": "url", "install_cmd": "string", "execute_cmd": "string" }
}
